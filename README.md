One original loading-screen tip in at most 200 characters — the kind of line a player actually wants to read while waiting: a genuinely useful warning about sprinting past ledges, with the loading bar itself doing the judging. Written for make.fun's "Loading Screen Gold: A Tip in 200 Characters" bounty.

## Run it

```sh
python3 main.py
```

This writes the tip to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt`) as a single UTF-8 line with no trailing newline.
